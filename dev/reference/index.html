Netlists

Microelectronics.Netlist — Type
Netlist(; title, models, includes, parameters, sources, components, globals)

A circuit, written as SPICE text by print(n) or string(n) and loaded into ngspice with load_netlist. All keywords are optional:

  • title: the first line of the netlist
  • models: Models and Subcircuit definitions
  • includes: Includes; the model_library by default
  • parameters: .param lines, in any form parameter_list takes (e.g. @table R C or (R=1u"kΩ", C=1u"nF"))
  • sources: Sources, e.g. from Vdc or Vsin
  • components: other elements, e.g. from Resistor
  • globals: nets shared by the whole circuit, including inside subcircuit definitions, e.g. globals=["vdd"] writes .global vdd

Subcircuit instances may only set parameters their subcircuit declares. To mix in SPICE text, use build_netlist.

Example

julia> n = Netlist(title="divider", includes=Include[], sources=[Vdc("in","in",0,1u"V")],
                   components=[Resistor("R1","in","out",1u"kΩ"), Resistor("R2","out",0,1u"kΩ")]);

julia> print(n)
* divider
Vin   in 0  dc 1
R1 in out 1000
R2 out 0 1000
.end
source
Microelectronics.load_netlist — Function
load_netlist(n)

Load netlist n into ngspice, replacing any circuit loaded before. n is a Netlist or SPICE text, such as the result of build_netlist or a netlist file read with read(file, String). Run an analysis on it with simulate.

source
Microelectronics.build_netlist — Function
build_netlist(s="";title="circuit",parameters="",models="",includes="",sources="",components="")

Constructs and loads a SPICE netlist with this format:

* <title>
<models>
<parameters>
<sources>
<components>
<s>
.end

globals names nets shared by the whole circuit, including inside subcircuit definitions, e.g. globals=["vdd"] writes .global vdd.

The positional argument s can be any SPICE-compatible text. The kwargs can be String or Vector{String} types, usually generated by other functions in the Microelectronics package. All args and kwargs are optional; if none are given, then an empty netlist is loaded.

Example

julia> title="Example Circuit";
julia> sources=[vdc("V1",1,0,1u"V")];
julia> components=[resistor("R1",1,0,1u"kΩ")];
julia> build_netlist(;title,sources,components)
Note: No compatibility mode selected!
Circuit: * example circuit
* Example Circuit

V1    1     0      DC 1

R1    1     0     1000

.end

Microelectronics.parameter_list — Function
parameter_list(x) -> Vector{Parameter}

The parameters in x, which can be a Parameter, a name => value pair, a (name, value) tuple, a named tuple (R=1u"kΩ", C=1u"nF"), a table from @table, nothing, or a vector or tuple of these. Names must be unique, ignoring case. Used by Netlist, Subcircuit and the element constructors, so they all accept the same forms.

source
Microelectronics.Parameter — Type
Parameter(name, value)
Parameter(name => value)
Parameter((name, value))

A named value: a .param line in a Netlist, a default in a Subcircuit, or an instance parameter such as a MOSFET's W. The value can be a quantity (written in SI units), a number, a SPICE expression as a string ("{2*R}"), or another parameter's name as a Symbol (:R, written {R}). The name can be a String or a Symbol.

Parameter(table) gives a vector of parameters from a table made with @table. Constructors take lists of parameters in many forms; see parameter_list.

Example

julia> p = Parameter("R", 1u"kΩ");

julia> (p.name, p.value)
("R", 1 kΩ)
source
Microelectronics.ParameterTable — Type
ParameterTable

A table of parameter names and values, as made by @table. It is an ordered dictionary from names (String) to values: entries keep the order they were given in, and it works like any AbstractDict:

julia> t = @table R=1u"kΩ" C=1u"μF";

julia> t["R"]
1 kΩ

julia> t["fc"] = Hz(1/(t["R"]*t["C"]));

julia> collect(keys(t))
3-element Vector{String}:
 "R"
 "C"
 "fc"

It is displayed, printed and interpolated as a report table; repr gives ParameterTable("R" => 1 kΩ, ...).

source

@table(p1, p2, ...)

@table p1 p2 ...

@table(p1=val1, p2=val2, ...)

Define a table of parameter names and values, a ParameterTable. Names are taken from variables or from the left of =; the table keeps their order and is displayed as a report table.

Microelectronics.Include — Type

An .include filename line, to read models or subcircuits from a file. A Netlist includes the package's model_library by default; give includes=[Include("my_models.sp"), ...] to change that.

source
Microelectronics.model_library — Function
model_library()

The path of the SPICE model library that comes with the package. A Netlist includes it by default. It defines op-amps (ideal_opamp, saturating_opamp, two_stage_opamp, ideal_ota, saturating_ota), diodes (D1N4004, D1N914, D1N4148, SFH235, SFH4554), BJTs (Q2N2222, Q2N2907A, Q2N3904, Q2N3906) and MOSFETs (ald1105n, ald1105p, CD4007N, CD4007P).

source
Microelectronics.Element — Type
Element

The supertype of everything that can go in a Netlist or Subcircuit: Components (resistors, capacitors, diodes, MOSFETs, subcircuit instances, ...), independent Sources, the controlled sources VCVS, VCCS, CCVS and CCCS.

string(e) gives the element's SPICE line.

source
Microelectronics.Component — Type
Component

A netlist element with a name, nodes, and optionally a value, a model name and instance parameters. Components are usually made with Resistor, Capacitor, Inductor, Diode, Subckt, Opamp, NMOS, PMOS or MOSFET.

Fields: name, species (e.g. "resistor"), prefix (the SPICE letter, e.g. "R"), nodes, value, model and parameters.

The keyword constructor Component(; name, species, prefix, nodes, value, model, parameters) adds the prefix to the name when it is missing.

source
Microelectronics.SpiceText — Type
SpiceText

SPICE text, as returned by build_netlist, spice_parameters and the element functions (resistor, vdc, mosfet, ...). It is an AbstractString, so it works anywhere a string does: compare it, split or replace it, interpolate it, or pass it to load_netlist. It differs only in how it is displayed, one line per row and without quotes, and so does a vector of them:

julia> build_netlist(; sources=[vdc("V1",1,0,1u"V")], components=[resistor("R1",1,0,1u"kΩ")])
* circuit
.include .../model_library.sp
V1    1     0      DC 1
R1    1     0     1000
.end

repr and string give ordinary strings.

Sources

Microelectronics.Source — Type
Source

An independent voltage or current source with one or more Waveforms, e.g. a DC value for the operating point, an AC magnitude for AC analyses and a sine for transient analyses. Sources are usually made with Vdc, Vac, Vsin, Vpulse, Vpwl or Vsource, and their current source equivalents (Idc, Iac, ...).

Fields: name, species ("vsource" or "isource"), prefix ("V" or "I"), nodes and waveforms.

See also alter, to change a sine source's settings.

source
Microelectronics.Waveform — Type
Waveform(kind, args...; kwargs...)

The value of an independent source: one of

  • Waveform(:dc, value), written DC value
  • Waveform(:ac, magnitude=1), written AC magnitude, for AC analyses
  • Waveform(:sin; offset, amplitude, frequency, phase), or Waveform(:sin, offset, amplitude, frequency, phase)
  • Waveform(:pulse; low, high, delay, risetime, falltime, width, period, pulses)
  • Waveform(:pwl, points), with points as Points or tuples

Defaults for the sine are 0 V offset, 5 mV amplitude, 1 kHz and 0°; for the pulse 0 to 5 V, no delay, 1 ns edges, 499 ns width and a 1 ms period. A sine's frequency may be given in rad/s; it is converted to Hz. A Source holds one or more waveforms. In a notebook, a source is displayed as a summary of its waveforms; print shows its SPICE line.

Examples

julia> print(Waveform(:sin; amplitude=1u"V", frequency=10u"kHz"))
 sin (0 1 10000 0 )

julia> print(Waveform(:dc, 5u"V"))
 dc 5
source
Microelectronics.Point — Type
Point(time, value)
Point((time, value))

One point of a piecewise-linear (PWL) waveform. Times and values can be quantities or plain numbers (seconds, and volts or amperes). A vector of (time, value) tuples can be used wherever points are expected, e.g. in Vpwl.

source
Microelectronics.Vdc — Function
Vdc(name, nplus, nminus, value=0; kwargs...)
Idc(name, nplus, nminus, value=0; kwargs...)

A DC voltage (current) source from nplus to nminus, e.g. 5u"V" (1u"mA"). A current source's current flows from nplus through the source to nminus.

Every source also takes the keywords dc, ac and pwl to add more waveforms, e.g. Vsin("in", 1, 0; amplitude=1u"V", ac=1) for a source that drives both transient and AC analyses. The V (or I) prefix is added to the name if it is missing.

Examples

julia> print(Vdc("DD", "vdd", 0, 5u"V"))
VDD   vdd 0  dc 5

julia> print(Idc("I1", "vdd", "d", 100u"μA"))
I1   vdd d  dc 0.0001
source

Microelectronics.NMOS — Function
NMOS(name, drain, gate, source, body=source; model="ald1105n", W, L, M, ...)
NMOS(; name, drain, gate, source, body=source, model="ald1105n", W, L, M, ...)

An n-channel MOSFET. The body is tied to the source unless given, and the model defaults to the ALD1105 n-channel device in the model library, whose default size is W = 20 μm, L = 10 μm.

julia> NMOS("M2", "d", "g", "s", 0; model="CD4007N", W=60u"μm", L=10u"μm")

Microelectronics.device_values — Function
device_values(name)

Operating values of MOSFET name in the latest operating-point, DC or transient analysis, with units:

  • id: current into the drain
  • vgs, vds, vbs: terminal voltages
  • vth: threshold voltage, including the body effect
  • vdsat: drain-source saturation voltage (vgs - vth for level-1 models)
  • gm, gds, gmbs: transconductance, output conductance, body transconductance
  • region: :cutoff, :triode or :saturation

Voltages and currents follow the circuit's sign convention, so for a PMOS vgs, vds, vth and id are normally negative. After an operating-point analysis each value is a single number; after a DC sweep or transient analysis each is a vector.

Example

julia> build_netlist(; sources=[Vdc("VDD","d",0,5u"V"), Vdc("VG","g",0,3u"V")],
                       components=[NMOS("M1","d","g",0)]);

julia> simulate(:op); device_values("M1")
(id = 0.001363 A, vgs = 3.0 V, vds = 5.0 V, vbs = 0.0 V, vth = 0.7 V, vdsat = 2.3 V,
 gm = 0.001185 S, gds = 3.45e-5 S, gmbs = 0.000... S, region = :saturation)

Microelectronics.independent_source — Function
independent_source(species;args...)

Instantiate an independent Voltage or Current source. species is "V" or "I".

Keyword arguments

All instances must have the positive and negative terminals assigned via nplus and nminus.

Optionally, a name can be given.

Remaining keyword arguments are specific to the desired source species.

  • DC source:
    • dc specifies the desired voltage or current
  • AC source:
    • ac specifies the AC magnitude (usually 1)
  • SIN source:
    • offset
    • amplitude
    • frequency
    • phase
  • PWL source:
    • points
  • PULSE source
    • high
    • low
    • width
    • period

If no keyword arguments are given, a zero-value source is instantiated.

Microelectronics.spice_parameters — Function

spice_parameters(p::AbstractDict,[keys...])

Return a String of SPICE parameter declarations using entries in dictionary p. If additional arguments are specified, then lines are output only for the specified keys.

Examples

julia> d = @table a=1u"V"  b=4u"ms";

julia> spice_parameters(d)
.param     a=1
.param     b=0.004

julia> spice_parameters(d,"a")
.param     a=1
