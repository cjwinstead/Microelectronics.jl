SPICE text functions

Circuits can also be written with functions that return each SPICE line as text. build_netlist takes their results, mixed with element objects and SPICE text written by hand, and loads the netlist:

build_netlist(; title="text", sources=[vdc("V1", 1, 0, 1u"V")],
                              components=[resistor("R1", 1, 0, 1u"kΩ")])
* text
.include .../model_library.sp
V1    1     0      DC 1
R1    1     0     1000
.end

Each function returns SpiceText, a string that is displayed without quotes, one line per row, and can be passed to load_netlist.
