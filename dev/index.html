Microelectronics.jl

Microelectronics.jl builds circuits in Julia, simulates them with ngspice (through NgHerb.jl), and reads, plots and tabulates the results. It is written for teaching circuit design in Jupyter notebooks, so component values carry units (1u"kΩ", 10u"nF") and results come back with units too.

Installation

The package is registered in the LEFT registry. In Julia's package mode (press ]):

pkg> registry add https://github.com/cjwinstead/LEFT_registry
pkg> add Microelectronics

using Microelectronics also loads Unitful (for u"..." units) and Plots, so results can be plotted right away.

A first circuit

An RC low-pass filter, its frequency response, and its cutoff frequency:

using Microelectronics

n = Netlist(title="RC low-pass",
            sources=[Vac("in", "in", 0)],
            components=[Resistor("R1", "in", "out", 1u"kΩ"),
                        Capacitor("C1", "out", 0, 1u"μF")])
load_netlist(n)
simulate(:ac; start=10u"Hz", stop=100u"kHz", steps=10)
measure(:cutoff; name="out")       # 159.4 Hz
bode("out")                        # magnitude and phase plots

print(n) shows the SPICE netlist that was simulated:

* RC low-pass
.include .../model_library.sp
Vin   in 0  ac 1
R1 in out 1000
C1 out 0 1e-06
.end
