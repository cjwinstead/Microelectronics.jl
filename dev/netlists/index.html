Building netlists

A Netlist is a circuit: a title, models and subcircuit definitions, .param parameters, sources and components. Each element is a Julia object that prints as one SPICE line, and print(n) shows the whole netlist.

n = Netlist(title="divider",
            sources=[Vdc("in", "in", 0, 1u"V")],
            components=[Resistor("R1", "in", "out", 1u"kΩ"),
                        Resistor("R2", "out", 0, 3u"kΩ")])
load_netlist(n)          # send it to ngspice
simulate(:op)
node"out"                # 750 mV

build_netlist does both steps at once and also accepts SPICE text; see SPICE text functions.

Names, nodes and values

Every element constructor takes its arguments in the order (name, nodes..., value), or all as keywords (Resistor(name="R1", nplus="in", nminus="out", value=1u"kΩ")).

  • Names get their SPICE prefix letter if it is missing: Resistor("load", ...) is Rload and Vdc("in", ...) is Vin. SPICE names are not case sensitive.
  • Nodes can be integers, strings or symbols. Node 0 is ground.
  • Values can be quantities with units, which are written in SI units (2.2u"kΩ" becomes 2200), plain numbers in SI units, SPICE text ("4.7k"), or a parameter name as a Symbol (:R, written {R}).

Components and sources

A source can have several values at once, for different analyses:

Vsin("in", "in", 0; amplitude=1u"V", frequency=1u"kHz", ac=1, dc=0u"V")
# Vin   in 0  sin (0 1 1000 0 ) ac 1  dc 0

The package's model_library is included in every netlist by default. It provides op-amp subcircuits (ideal_opamp, saturating_opamp, ...), diodes (D1N4004, D1N914, ...), BJTs and MOSFETs. More models go in models, as Models, and more files in includes, as Includes.

Parameters

Parameters become .param lines, and elements refer to them by name with a Symbol. They can be given in whatever form is convenient:

n = Netlist(title="parameterized divider",
            parameters=(Rtop=1u"kΩ", Rbot=3u"kΩ"),
            sources=[Vdc("in", "in", 0, 1u"V")],
            components=[Resistor("R1", "in", "out", :Rtop),
                        Resistor("R2", "out", 0, :Rbot)])
* parameterized divider
.include .../model_library.sp
.param  Rtop=1000
.param  Rbot=3000
Vin   in 0  dc 1
R1 in out {Rtop}
R2 out 0 {Rbot}
.end

The same parameters could be written as @table Rtop Rbot (taking the values of variables Rtop and Rbot), ["Rtop" => 1u"kΩ", "Rbot" => 3u"kΩ"] or [Parameter("Rtop", 1u"kΩ"), Parameter("Rbot", 3u"kΩ")]; see parameter_list. A parameter can be an expression of others: Parameter("R2", "{3*Rtop}").

Values with units are written in SI units. Angular frequencies are written in Hz: 1u"krad/s" becomes 159.155, which is what a source's frequency needs.

SPICE names are not case sensitive, so giving R and r is an error, as is giving any name twice.

Subcircuits

A Subcircuit is a reusable block with terminals and default parameters. Put its definition in models and add instances with Subckt, connected to nodes in the order of its terminals. An instance can override the defaults:

divider = Subcircuit(name="divider", terminals=["top", "mid"], parameters=(R=1u"kΩ",),
                     components=[Resistor("R1", "top", "mid", :R),
                                 Resistor("R2", "mid", 0, :R)])
n = Netlist(title="two dividers", models=[divider],
            sources=[Vdc("in", "in", 0, 2u"V")],
            components=[Subckt("X1", ["in", "a"], "divider"),
                        Subckt("X2", ["a", "b"], "divider", (R=10u"kΩ",))])
.subckt divider top mid
+params: R=1000
R1 top mid {R}
R2 mid 0 {R}
.ends
...
X1 in a divider
X2 a b divider R=10000

ngspice silently ignores an instance parameter that its subcircuit doesn't declare, so a misspelled name would have no effect. A Netlist checks instances against the subcircuits it defines:

Netlist(models=[divider], components=[Subckt("X3", ["in", "c"], "divider", (Rx=1,))])
# ArgumentError: X3 sets parameter Rx, but subcircuit divider only has R

Global nets

Nets such as a supply rail can be shared by the whole circuit, including inside subcircuits, without passing them in as terminals. Ground (0) is always global.

load = Subcircuit(name="loaded", terminals=["out"],
                  components=[Resistor("RL", "vdd", "out", 10u"kΩ")])
n = Netlist(title="globals", globals=["vdd"], models=[load],
            sources=[Vdc("DD", "vdd", 0, 5u"V")],
            components=[Subckt("X1", ["out"], "loaded"), Resistor("R2", "out", 0, 10u"kΩ")])

This writes .global vdd at the top of the netlist.
