Microelectronics.curve_series — Method
curve_series(x, ys, labels)

Split each signal in ys into one series per curve of the latest analysis (see sweep_curves), for plotting. Returns vectors of x data, y data and labels.

source
Microelectronics.find_vec — Method
find_vec(name; node=true, branch=true)

Return the name of the result vector for a node voltage, a source current or a MOSFET drain current in the latest analysis. name is a node name ("out", 2), a voltage source, whose current is the vector "<name>#branch", or a MOSFET, whose drain current is "@<name>[id]". Case doesn't matter. With branch=false only node voltages are matched; with node=false only currents. Throws an ArgumentError listing the available names if there is no match.

Microelectronics.nextname — Method
nextname(prefix)

Increment the counter for device prefix prefix and return the next automatic device name. Used when an element is created without a name.

Examples

julia> Microelectronics.nextname("R")
"R1"

julia> Microelectronics.nextname("R")
"R2"
